## AI Chatbot Assistants

> AI chatbots are the **front door** to the bot ecosystem. They range from general-purpose assistants (ChatGPT, Claude) to specialized research tools (Perplexity). The key choice is between **breadth** (general chat) and **depth** (domain-specific). Most power users run 2–3 for different tasks.

### How to set up
1. Sign up at the bot's website or download the app
2. Choose free tier or subscribe for higher limits
3. For API access: get an API key and use the official SDK or REST API
4. For integrations: connect via Zapier, Make, or native plugins

## AI Coding Agents

> Coding agents turn natural language into working code. The category split is **in-editor** (Cursor, Claude Code — they live inside your IDE) vs **async/cloud** (Devin, Codex — they run autonomous jobs). For most teams, an in-editor agent + a PR-review bot is the practical stack.

### How to set up
1. Install the editor extension or CLI (`npm i -g`, VS Code marketplace, etc.)
2. Authenticate with your GitHub/account
3. Add API key to environment (never paste secrets in chat)
4. Connect to your repo; start with small, reviewable tasks

## Grok Bot Setups (Ready-to-Use)

> [Grok Bot](https://x.ai/bot) is xAI's platform for **named, persistent bots** with connected tools and a hard approval boundary. Each setup below is a *paste-ready job* — a profile description, a first task, and what it must never do without your OK. Sourced from [botdirectory.ai](https://botdirectory.ai) (100+) and [Promptway](https://promptway.com/tools/bots) (13 curated).

### How to set up a Grok Bot
1. Install Grok Bot on Mac, Windows, or iPhone (needs SuperGrok Heavy, Cursor Ultra, or Cursor Teams Premium)
2. Create a Bot; give it the name + one-line job from the listing
3. Paste the profile description into **Bot actions → Edit Profile**
4. Sign in to the tools it names (you type passwords; never put secrets in chat)
5. Send the first task, review the result, save the skill only after output is something you'd sign

## AI Web Crawlers & Indexers

> Web crawlers are **bots that fetch your pages** — for search (Googlebot), AI training (GPTBot, ClaudeBot), or products (Applebot). From [bots.fyi](https://bots.fyi) (200+ indexed). ✅ = verified, ⚠️ = unverifiable. Control them via `robots.txt` and the listed user-agent tokens. The split that matters: **AI Training** crawlers may ingest your content into models; **No Training** crawlers (ChatGPT-User, DuckAssistBot) only fetch on a specific user request.

### How to set up / control
- Allow/block a crawler: `User-agent: <token>` + `Allow:` / `Disallow:` in `robots.txt`
- Opt out of AI training: `User-agent: GPTBot` → `Disallow: /` (or use Google-Extended, ClaudeBot, etc.)
- Verify a bot is legit via the `bots.fyi` verification badge before allowlisting

## How to Set Up AI Bots

### A. Consumer Chatbot (e.g., ChatGPT, Claude)
1. Go to the site, sign up (Google/Apple/Microsoft SSO works)
2. Start free; upgrade for higher limits (Pro/Team/Enterprise)
3. For code: install the VS Code / JetBrains extension
4. For API: dashboard → create key → `export OPENAI_API_KEY=...` (never commit it)

### B. Coding Agent (e.g., Cursor, Claude Code)
1. Cursor: download from cursor.com, import your VS Code profile
2. Claude Code: `npm install -g @anthropic-ai/claude-code` then `claude` in your repo
3. Add your API key to the environment, not the chat
4. Start with: "Review this file for bugs" before autonomous edits

### C. Grok Bot (xAI)
1. Install Grok Bot (Mac/Win/iPhone); needs SuperGrok Heavy or Cursor Ultra/Teams
2. Create a Bot → name + one-line job
3. Paste the profile from a listing into **Edit Profile**
4. Sign in to each named integration (you type passwords)
5. Send first task → review → save skill only after good output

### D. Web Crawler Control (your site)
```txt
# Block all AI training crawlers
User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

User-agent: Google-Extended
Disallow: /

# Allow verified monitoring + search
User-agent: Googlebot
Allow: /

User-agent: Datadog
Allow: /
```
Validate at [bots.fyi/stats](https://bots.fyi/stats) and test with the crawler's official tool.

### E. Webhook Bot
1. In the source app (GitHub, Stripe), go to Webhooks → Add
2. Paste your endpoint URL (use Hookdeck for a debug proxy)
3. Select events; verify signature (`X-Hub-Signature`) before trusting payloads

## Ranking Methodology

Bots are ranked by a simple **three-axis score**:

| Axis | Weight | What it measures |
|---|---|---|
| **Adoption** | 40% | User base, market share, ecosystem size |
| **Capability** | 35% | Task quality, context window, tool use |
| **Trust** | 25% | Verification (✅), open-source, privacy posture |

- ⭐ = top in its category on adoption + capability
- ✅ = verified identity (bots.fyi) or official vendor
- 🔓 = open source / self-hostable (full data control)
- 💰 vs 🆓 vs ☁️ = pricing & delivery model

> **Segment summary:** Consumer chatbots are a **duopoly+** (ChatGPT/Claude lead, Gemini close). Coding agents are **editor-native** (Cursor/Claude Code). Grok Bots are the **workflow layer** (paste-ready jobs with approval gates). Web crawlers are **infrastructure** you control, not choose.
